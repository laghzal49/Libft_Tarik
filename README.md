# Libft_Tarik

A 42 School project: a custom reimplementation of core C standard library functions (memory, string, and conversion utilities) plus a singly linked-list utility set, with bonus functions included.

## Contents

- Memory functions: `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_memchr`, `ft_memcmp`, `ft_calloc`
- String functions: `ft_strlen`, `ft_strlcpy`, `ft_strlcat`, `ft_strchr`, `ft_strrchr`, `ft_strncmp`, `ft_strnstr`, `ft_strdup`, `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`
- Conversion / output: `ft_itoa`, `ft_atoi`, `ft_toupper`, `ft_tolower`, `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`
- Character checks: `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`
- Bonus linked-list functions: `ft_lstnew`, `ft_lstadd_front`, `ft_lstadd_back`, `ft_lstsize`, `ft_lstlast`, `ft_lstdelone`, `ft_lstclear`, `ft_lstiter`, `ft_lstmap`

See `LIBFT_DOCUMENTATION.md` for detailed function-by-function documentation.

## Build

```sh
make
```

This produces `libft.a`, a static library you can link into other 42 projects.
